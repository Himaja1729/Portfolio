# Personal Portfolio

This is my personal portfolio website that showcases my background, skills, and projects. It is designed to reflect my professional journey and provide visitors with an overview of my capabilities.

The portfolio includes:

- An introduction and about me section.
- A list of technical skills and tools I work with.
- A portfolio of selected projects with descriptions and links.
- Contact information for professional inquiries.
- A clean, responsive layout that works across all devices.

This project was created to present my work in a structured and visually appealing way and serves as a platform to highlight my achievements and experiences.
